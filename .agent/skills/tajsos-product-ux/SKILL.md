# TajsOS Product UX Overlay

## Core stance

- The product name is **TajsOS** (not TajOS).
- TajsOS is **LifeOS-first**, not just a generic second-brain app.
- Prefer one cohesive system over feature sprawl.
- Question weak abstractions and vague pseudo-features.

## Product focus

- Default MVP focus stays centered on dashboard/briefing, notes, and tasks unless current repo
  direction clearly changed.
- Favor decisions that strengthen shared life-object flows over isolated feature silos.

## UX quality bar

- Preserve modern, polished, visually coherent UX.
- Keep interaction patterns consistent across screens.
- Use existing theme/resources conventions; avoid one-off user-facing strings, tokens, or naming
  drift.

## Priority reminder

When guidance conflicts, follow:
user instruction -> repo reality/canonical docs -> this overlay -> generic skills -> external
examples.
