# TajOS Roadmap
---

## Core Direction

TajOS should do 4 things extremely well:

- [ ] Capture chaos
- [ ] Preserve context
- [ ] Help the user start moving
- [ ] Reveal patterns without requiring exhausting manual input

Everything else is an extension of those.
